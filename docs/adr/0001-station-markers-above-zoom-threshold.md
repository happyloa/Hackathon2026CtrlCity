# 逐站標記在近距縮放層級恢復，疊加於色斑之上

02 票拿掉了逐站上色圓點，改成純色斑疊加，理由是逐站上色在密集城區會讓「站多」被誤讀成「更嚴重」，且色斑本身足以回答「這一帶在燒」（見 CONTEXT.md「鄰近群」條目）。上線後調度人員反映：拉近到街道層級後，色斑經常整片融合，找不到、點不到特定一站——色斑回答的是「這一帶」，從來就沒打算回答「哪一顆是哪一站」。

決定加回一層**站點標記**（見 CONTEXT.md），依嚴重度上色，但只在畫面拉近到足以逐站辨識的縮放層級才出現與可互動；低於這個層級維持純色斑，因為城市尺度下 1,600+ 站的標記一樣會擠成一片，02 當初的密度誤讀顧慮在那個尺度依然成立。標記只負責「點選單一站」，色斑與鄰近群（03 票「點色斑展開清單」）維持原本角色與行為，兩種互動並存，這次不移除、也不整合。
