## 必講的三個亮點

1. 即時：新北官方資料、五分鐘對齊檢查、真有變更才更新畫面。
2. 預測：即時模式提供 30／60 分鐘歷史基線風險指標，歷史回放提供 30／60／120 分鐘情境；指標不是校準後機率。
3. 決策：紅色缺車、藍色缺位、灰色服務狀態待確認；補車／移車建議都要由人員覆核，系統不自行派車。

## 被問到技術時

- 歷史資料為什麼穩定：三個情境在 build 時輸出成靜態 JSON，CDN 直接提供，避免在 edge 解析大型資料而觸發 1102。
- 為什麼還有 Function：新北公開來源的 CORS 不允許任意網站直接讀取，所以只保留一條不解析、不儲存的同源即時轉送。
- 有沒有資料庫：沒有 KV、D1、R2，也沒有付費資源。
- 有沒有真的使用 Bedrock：沒有。Demo 是可追溯 template 摘要；AWS／Bedrock 是未部署的遷移骨架。
