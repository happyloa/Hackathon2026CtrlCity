# 操作使用說明

這套 Demo 讓調度人員快速看懂未來 60 分鐘的站況，並參考建議路線。平台只做分析，不會派車。

## 首頁

1. 先看資料時間，以及未來 60 分鐘需要注意的站點。
2. 允許定位時，附近站點判斷一致才會預選行政區；判斷不明或定位失敗時顯示全市。
3. 切換行政區後，數字、建議和地圖會一起更新。
4. 點清單或地圖上的站點，查看現在庫存、歷史基線與 60 分鐘推估。
5. 按「立即更新」取得最新官方站況。

## 站點總覽

- 可搜尋站名，或篩選全部、缺車、缺位、穩定、資料不足與服務異常。
- 需要注意的站點會排在前面；分數只用來排序，不是發生機率。
- 服務異常會另外標示，也不會排進搬運路線。

## 調度規劃

- 風險決定先後、庫存決定搬多少，距離用來挑選合適站點。條件接近時，優先把滿站的車送往缺車站。
- 系統先假設每台調度車可載 12 台，再把 2.5 公里內的需求合併成一條路線。
- 路線會列出停靠順序、取放車數、載量與估算距離，並保留安全庫存。
- 距離是站點間直線估算，不是道路導航；目前也沒有真實車隊資料。

## 地圖顏色

| 顏色 | 意思 |
| --- | --- |
| 紅 | 目前或 60 分鐘後有缺車風險。 |
| 藍 | 目前或 60 分鐘後有缺位風險。 |
| 粉紅底圈 | 相鄰 300 公尺的風險站形成一群。 |
| 灰 | 官方停用或疑似服務異常，不納入調度。 |
| 黃 | 未匹配歷史基線，只顯示即時庫存。 |
| 綠 | 目前穩定，車位供需較平均。 |
| 紫 | 目前穩定，可借車占總車柱至少三分之二。 |
| 藍綠 | 目前穩定，可還位占總車柱至少三分之二。 |
