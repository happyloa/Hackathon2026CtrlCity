# 操作使用說明

這套 Demo 提供即時風險分析與調度規劃，不確認案件、不送出派車命令。

## 首頁

1. 查看官方資料時間、60 分鐘風險摘要與地圖。
2. 選擇行政區後，數字、建議與地圖範圍會同步更新。
3. 點站名或地圖點位，比較目前庫存、歷史基線與 60 分鐘推估。
4. 「立即更新」會重新取得官方站況並計算風險。

## 全部風險

- 可依行政區及「全部／缺車／缺位／服務異常」篩選。
- 告警優先分由風險、當下空滿、缺口與資料品質組成；它是排序分，不是機率。
- 服務異常獨立顯示，不納入搬運建議或路線。

## 調度規劃

- 風險分數決定處理先後；缺口覆蓋率與安全庫存決定可搬數量；距離決定配對成本。條件相近時，優先把滿站的車直接搬到缺車站。
- 系統以 12 台容量車輛為假設，先處理高優先建議，再插入 2.5 公里內的相鄰需求。
- 路線顯示停靠順序、取放車數、車上載量與估算距離，並保留站點安全庫存。
- 距離為 Haversine 直線估算，不代表實際道路、工時或最佳路線；目前沒有真實車隊資料。

## 地圖顏色

| 顏色 | 意思 |
| --- | --- |
| 紅 | 目前或 60 分鐘後有缺車風險。 |
| 藍 | 目前或 60 分鐘後有缺位風險。 |
| 灰 | 官方停用或疑似服務異常，不納入調度。 |
| 橘 | 未匹配歷史基線，只顯示即時庫存。 |
| 綠 | 已匹配基線且目前無明顯風險。 |
