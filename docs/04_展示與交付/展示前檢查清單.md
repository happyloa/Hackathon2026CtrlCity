# 展示前檢查清單

## 系統

- [ ] 正式網址可開啟，桌機與手機沒有水平捲動或文字截斷。
- [ ] 淺／深色、鍵盤焦點、彈窗關閉與返回流程正常。
- [ ] 「即時調度」顯示資料時間、全市站點、工作佇列與風險地圖。
- [ ] 行政區／站名搜尋、站點詳情與 600m 替代還車資訊可操作。
- [ ] 「全部風險」可確認；「全部任務」可展開試算與指派。
- [ ] 「歷史演練」三個回放情境可載入，重新整理後 Demo 狀態會重置。
- [ ] `npm test`、`npm run data:validate`、`npm run typecheck`、`npm run build` 均通過。

## 三分鐘操作

1. 即時調度：指出資料時間與最高優先任務。
2. 地圖：點一站，比較現在／歷史基線／60 分鐘推估。
3. 任務：展開影響試算，再示範人工指派。
4. 歷史演練：說明保留測試與反事實試算。
5. 結尾：主張「增進預判能力」，不宣稱已降低真實空滿率。

## 備援與口徑

- 官方來源失敗：切換「歷史演練」，不要把回放稱為即時。
- 風險值是排序分數，不是發生機率；確認與指派不會通知機關或真實車隊。
- 「AWS AgentCore 覆核」只在正式環境啟用；上線前依[AWS 正式環境交接](../03_實作與驗證/AWS正式環境交接.md)確認權限、預算與清理方式。
