# 命題需求對照

範圍固定為新北市 YouBike；以下只列目前可驗證能力，不把規劃寫成已完成。

| 命題重點 | Demo 實作 | 界線 |
| --- | --- | --- |
| 官方即時資料 | 讀取新北市站況，顯示資料時間、行政區搜尋、地圖與庫存。 | 來源失敗會明示，不以歷史資料冒充即時資料。 |
| 歷史資料與預判 | 六個月資料轉為站點 × 半小時基線；即時模式提供 60 分鐘風險，歷史演練可重現固定情境。 | 風險分數是可解釋排序，不是事件機率。 |
| 無車／無位警示 | 將目前空滿與預判風險整理成「全部風險」待確認清單。 | 即時持續時間不跨頁累積，確認狀態只留在瀏覽器。 |
| 調度決策支援 | 「調度工作佇列／全部任務」提供來源、目的、建議車數、距離與影響試算。 | 不會建立正式工單、導航路線或直接派車。 |
| 效益驗證 | 保留測試指標與歷史庫存反事實試算可重現。 | 可主張增進預判能力；不能宣稱已達成真實營運 KPI。 |
| AWS 與生成式 AI | 已備妥 S3／CloudFront、Lambda 即時代理、AgentCore 覆核契約與精選知識上傳流程。 | 正式 AWS 資源與 Knowledge Base 尚未建立；Agent 只解釋既有結果。 |

命題要求的「即時視覺化、需求預判、持續風險警示、調度支援」已有 Demo 主線；營運化仍需通知／案件保存、真實車隊資料與實際介入成效。

數值依據見[歷史風險基線評估](歷史風險基線評估.md)，資料方法見[預測與資料方法](預測與資料方法.md)，AWS 待辦見[AWS 正式環境交接](AWS正式環境交接.md)。
