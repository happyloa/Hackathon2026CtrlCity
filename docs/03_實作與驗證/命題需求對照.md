# 命題需求對照

範圍固定為新北市 YouBike；平台提供分析與預測，不確認案件、不送出派車命令。

| 命題重點 | Demo 實作 | 界線 |
| --- | --- | --- |
| 官方即時資料 | 首頁顯示資料時間、行政區、地圖，以及穩定／風險／服務異常站點總覽。 | 來源失敗會明示，不以歷史資料冒充即時資料。 |
| 歷史資料與預判 | 六個月資料轉為站點半小時基線，與即時庫存產生 60 分鐘風險。 | 歷史資料只作基線；分數不是事件機率。 |
| 無車／無位警示 | 站點總覽可依行政區查看全部、缺車、缺位、穩定、資料不足與服務異常站點。 | 服務異常獨立顯示，不納入調度路線。 |
| 調度決策支援 | 將單站建議整合為 12 台容量的多站搬運路線，顯示停靠順序、載量與距離。 | 屬啟發式分析；無道路時間、車隊位置或正式工單。 |
| 可解釋排序 | 告警優先分拆為風險、當下空滿、庫存缺口與資料品質。 | 用於排序，不代表發生機率或執行結果。 |
| AWS 與生成式 AI | 已備妥 AWS 部署骨架與 AgentCore 分析說明契約。 | 正式環境仍待主辦方帳號與權限。 |

Demo 已涵蓋即時視覺化、60 分鐘預判、風險分類與多站調度規劃；真實營運仍需道路、車隊及介入成效資料。

方法見[預測與資料方法](預測與資料方法.md)，AWS 待辦見[AWS 正式環境交接](AWS正式環境交接.md)。
