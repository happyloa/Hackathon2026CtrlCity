# 預測與資料方法

## 資料來源

- 官方即時站況經唯讀 `/api/v1/live-stations` 取得；代理不保存資料。
- 主辦方六個月 CSV 只留在本機 `docs/資料集/`，不進 Git、瀏覽器或雲端。
- 建置時只輸出壓縮後的「站點 × 48 個半小時時槽」統計與三個回放情境。

## 60 分鐘判讀

```text
官方目前庫存 + 同站 60 分鐘後歷史時槽
→ 現在／歷史基線／推估庫存
→ 風險排序、告警與搬運建議
```

站點以規格化後的行政區與站名唯一匹配。樣本至少 6 筆才標示充足；樣本較少會提示，無法唯一匹配或非營運站只顯示即時庫存。

畫面主要顯示「現在、歷史基線、60 分鐘推估」及排序分數。分數不是發生機率，所有告警與任務都要人工覆核。

目前空／滿站即使沒有基線仍會告警；但未對照基線的站點不會被當成 60 分鐘安全的搬運來源或替代還車站。

## 驗證與限制

- 歷史回放只使用回放時間以前的資料建基線，避免未來資料洩漏。
- 評估採時間切分；指標以[歷史風險基線評估](歷史風險基線評估.md)為準。
- 目前未納入天氣、活動、捷運班次、道路時間或真實調度紀錄。
- 即時更新只在頁面開啟時運作；確認與指派狀態重新整理後會重置。
- 官方來源不可用時，改用明確標示的「歷史演練」完成展示，不把回放說成即時。
