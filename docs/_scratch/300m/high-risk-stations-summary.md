# 高風險站點分析（共 1540 站中，取前 60 名）

## 方法
- 用既有的 lowBikesRate/lowDocksRate（門檻 = max(2, ceil(總車柱數 x 0.1))），不重跑 F1。
- 每站的 combinedRisk = 所有樣本數 >= 6 的「星期 x 時段」格子，依樣本數加權平均 lowBikesRate + lowDocksRate。
- 300m 內的站點會被歸成同一群（跟既有的鄰站失效群組半徑一致）。
