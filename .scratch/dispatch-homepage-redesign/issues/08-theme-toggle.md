# 08: 深色/淺色主題切換

> **先讀(冷啟動必要脈絡):**
>
> - `.scratch/dispatch-homepage-redesign/spec.md` —— 完整的問題陳述、決策依據與範圍界線
> - `docs/02_研究與設計/map-library-selection.md` 的免金鑰底圖一節 —— **地圖為什麼不跟著變深色**。這不是沒做完,是查證後的決定:免金鑰的深色圖磚事實上不存在,所有提供深色的供應商都需要金鑰或帳號。
>
> **範圍外:** 淺色主題沒有設計稿(既有的 21 張設計稿全為深色),配色由實作者依既有的 token 語意決定即可,不需要等設計。

**What to build:** 讓調度人員依環境選擇介面明暗。

夜班長時間盯著螢幕需要深色,明亮的辦公室則需要淺色。**深色為預設**,提供一顆按鈕切換為淺色。

**地圖底圖不隨主題變動,恆為淺色。** 這是刻意的:經查證,免金鑰的深色圖磚事實上不存在(所有提供深色的供應商都需要金鑰或帳號註冊),而在黑客松環境下多一個部署期金鑰就多一個風險。淺色底圖的街道與地名始終清楚可辨,這對判讀位置比配色一致更重要。

樣式已全面以 CSS 變數 token 化,且全專案沒有使用任何深色模式的 utility class,所以主題切換是替換一組 token 的預設值,不需要逐一改寫元件。
