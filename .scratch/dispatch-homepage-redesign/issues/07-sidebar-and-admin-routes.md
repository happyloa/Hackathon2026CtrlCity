# 07: 左側 sidebar 導覽與 admin 路徑

> **先讀(冷啟動必要脈絡):**
>
> - `.scratch/dispatch-homepage-redesign/spec.md` —— 完整的問題陳述、決策依據與範圍界線
> - `CONTEXT.md` —— 領域詞彙,特別是「調度人員」與「分析師」是兩種不同觀眾
>
> **本票不改任何頁面的內容,只改導覽與路徑。** 這是四張可立即開始的票之一,與其他票沒有相依,但搬移路徑會碰到其他票也會碰的頁面,先做完可以減少後續衝突。

**What to build:** 讓導覽位置固定好找,並把分析師的頁面與調度人員的日常動線分開。

左側固定 sidebar,**三項**:首頁(調度)、站點總覽、調度規劃。這三項是調度人員的日常動線。

**營運 ROI 與營運調整移到 `/admin` 路徑之下,但不進 sidebar。** 它們是分析師與管理員的頁面,不該佔用調度人員的導覽空間;管理員以網址直接進入,展示時可用來檢查資料。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent
